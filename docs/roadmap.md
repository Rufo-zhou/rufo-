# Roadmap

## 近期

- 增加单元测试。
- 增加 `requirements.txt` 或 `pyproject.toml`。
- 为输出 JSON 增加更稳定的 schema。
- 为常见主题补充示例输入和示例输出。
- 增加更多剧本格式识别规则。
- 为视频工作流增加分镜数量和镜头类型配置。

## 中期

- 将单文件脚本拆分为更清晰的包结构。
- 增加正式 CLI 入口。
- 增加更多主题模板。
- 改进 OpenAI API 模式下的错误处理和重试策略。
- 支持角色参考图、分镜图和视频提示词的一键导出模板。

## 长期

- 接入真实图片生成 API。
- 支持 ComfyUI、Stable Diffusion WebUI 或其他渲染后端。
- 支持 AI 视频模型 API 后端。
- 增加 Web UI 或桌面端交互界面。
- 增加批量任务和模板管理能力。
