# Security and Privacy

## 默认隐私边界

- 默认模式只在本地读取输入图片路径和文件内容，不会上传图片。
- 输出文件写入用户指定的本地目录。
- `OPENAI_API_KEY` 只从环境变量读取，不会写入输出 JSON 或文本文件。

## 输入校验

海报工作流会检查：

- 文件是否存在
- 路径是否指向普通文件
- 扩展名是否属于 JPG、JPEG、PNG、WebP
- 文件大小是否超过限制
- 文件头签名是否符合真实图片格式
- 主题是否为空或过长

视频工作流会检查：

- 剧本文本是否存在
- 文件扩展名是否属于 TXT、Markdown、Fountain 或 screenplay
- 文件大小是否超过限制
- 文本是否为 UTF-8
- 文本是否为空或过长
- 是否含危险控制字符
- 是否疑似包含 API key 或 token

## OpenAI API 模式

开启 `--use-openai` 后，文本上下文会发送给 OpenAI API。当前原型不会把图片二进制上传给 OpenAI；视频工作流会把剧本文本片段作为上下文发送给 OpenAI。

使用 API 模式时请注意：

- 不要在命令行历史、代码或 README 中写入真实 key。
- 不要提交 `.env` 文件。
- 不要把真实个人照片作为公开测试样例提交到仓库。

## 公开仓库注意事项

请不要提交：

- API key、token、cookie 或私有配置
- 真实肖像、身份证件、联系方式等隐私数据
- `outputs/` 生成结果
- 临时图片、缓存、虚拟环境和 IDE 配置

## 报告安全问题

安全策略入口保留在根目录 [SECURITY.md](../SECURITY.md)。如果发现问题，请按其中说明提交报告。
